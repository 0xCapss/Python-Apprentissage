# Labs - Index

Notes de préparation et modèles pour les labs HackTheBox du plan de carrière.

## Règle d'or : rien de public
Le dépôt GitHub est public et HackTheBox interdit de partager les solutions des Pro Labs et Mini Pro Labs. Les notes **remplies** (journal, rapport, schémas, identifiants) restent donc sur ta machine : tout fichier dont le nom contient « privé » ou « prive » est ignoré par git (voir `.gitignore`). Ici, on ne range que des modèles et des fiches de préparation, sans solution.
